## 🚀 What I'm Shipping Right Now

### 🔴 SENTINEL — Behavioral Accountability AI
> *"Your productivity data doesn't lie. You do."*

Real-time Windows activity monitoring system that **objectively scores focus** using behavioral signals — not self-reporting, not vibes.

| Layer | Tech | What it does |
|---|---|---|
| 🖥️ Monitor | Python | Captures active window, app, idle time every second |
| ⚙️ Backend | FastAPI | Processes behavioral streams, computes focus scores |
| 📊 Dashboard | React + Recharts | Live productivity analytics with TailwindCSS |
| 🗄️ Storage | SQLite | Persistent behavioral history |

**The insight:** Accountability systems fail because people game them. SENTINEL uses behavioral telemetry — you can't fake what you're actually doing on your screen.
